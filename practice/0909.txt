s=Student()
s 는 참조변수 
Student 는 클래스 객체선언 
참조변수는 주소값이 저장이 되어져 있기에 그냥 저장하면 주소값이 변경될 수 있음. 
객체선언을 해야지만 실행이 됨. 

생성자를 안 만들경우 모든 정보를 직접 입력해야함
생성자를 만들경우 값을 바로 입력할 수 있음 

def __init__(self): 로 지정!!! self 뒤에 매개변수 입력
여러 개를 입력할 경우 가변매개변수로 사용 
생성자는 객체가 선언될 때 제일 먼저 자동으로 실행되는 것 

객체선언이 함수와 다른 이유는 첫글자가 대문자임 

클래스 내에 있는 함수를 메소드라고 지칭 
메소드보다는 함수라고 읽음 

self.no = no 
no는 함수 내 지역변수 
self.no 는 클래스 내 함수 
self를 안 쓸 경우 클래스 내 함수로는 값이 들어가지 않음. 

get : 읽어오는 것
set : 저장하는 것 

def to.string(self) 보다는 def __str__(self) 로 사용하는 것이 좋음
